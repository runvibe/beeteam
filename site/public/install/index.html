Install Bee Team

This guide is for the assistant helping a user install Bee Team on their computer.

  1. Identify the user's harness, operating system, architecture and existing installation. Preserve project files, local data and customized skills.
  2. Read the installation manifest. Require a stable release, a matching platform artifact, and the official Bee Team repository with a skills ref matching the release version. If the manifest or package is unavailable, report that installation is unavailable and stop.
  3. Read skills/setup-bee-team/references/bootstrap.md from that verified release tag. Follow its project-scoped instructions for Codex, Claude Code or GitHub Copilot. For another harness, follow its manual installation instructions. Confirm the harness can load setup-bee-team.
  4. Use setup-bee-team to validate the download size and SHA-256, install or update the appropriate binary, and start or reuse the local service. Check the local API identity and version. Avoid starting a second process.
  5. Report the installed version and connection result. Ask the user to open Bee Team and grant browser access to the local service if prompted.
