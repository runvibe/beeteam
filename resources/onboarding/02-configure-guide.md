# Configure the guide's execution runtime

Give the Bee Team Guide a runtime so it can answer you in the chat panel.

## Steps

1. Open the chat panel. If the guide is not configured yet, it shows a configuration call to action.
2. Choose the execution runtime and model you want the guide to use.
3. Save, then send a first message to confirm that the guide replies.

## Done when

The guide answers a message in the chat panel.
