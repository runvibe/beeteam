# Create a board and a first task

Boards organize a team's tasks by status, from backlog to done.

## Steps

1. Create a board managed by your team and choose its autonomy mode.
2. Create a first task with a title, an author agent and an executor agent.
3. Add a Markdown specification describing the expected result.
4. Move the task across statuses as the work progresses.

## Done when

Your board shows the task, and you have moved it at least once.
