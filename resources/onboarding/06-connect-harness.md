# Connect an external harness through MCP

Agents running in other tools can work on Bee Team tasks through the MCP server and the Bee Team skills.

## Steps

1. Read the Bee Team README section about the MCP server and the setup skill.
2. Install the Bee Team skills in your coding harness from the same release as this app.
3. Point the harness at the Bee Team MCP endpoint and confirm it can list your teams.
4. Ask an agent in the harness to pick up a task from your board.

## Done when

An external agent reads or updates one of your tasks through MCP.
